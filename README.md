# ChemVerse 🧪🌌

جهان سه‌بعدی شیمی — مشاهده مولکول‌ها به صورت تعاملی و زیبا.

**ساخته شده توسط امیرحسین بخشی**

## مولکول‌های موجود

- آب (H₂O)
- دی‌اکسید کربن (CO₂)
- متان (CH₄)
- آمونیاک (NH₃)
- اتانول (C₂H₅OH)
- بنزن (C₆H₆)

## اجرا

```bash
npm install
npm run dev
```

برو روی [http://localhost:3000](http://localhost:3000)

## کنترل‌ها

- درگ کردن → چرخش مولکول
- اسکرول → زوم
- دکمه‌های پایین → تغییر مولکول
